- recipient_snapshot04unique(version,person)อาจไม่ครอบคลุมsamepersonหลายcontextrole; exactbusinesskeyให้O08ยืนยัน ไม่เปลี่ยนชื่อผู้รับกลางหรือautograntorgทั้งชุด due_date/recordACL/number-eventsยังไม่มีใน04 ต้องADR และmigrationเดียวกับscope/filesที่พร้อม

## 3 DTO และ query เสนอ

AuthorizedRecordDTO allowlist: opaque record/version IDs, registertypeที่อ่านได้, ordinalเป็นstring, formattedsnapshot, permittedsubject, priority/confidentialityที่policyให้ดู, dates, permittedrecipient-summary, approvedfilerefopaque IDs และauthorizedbusinessrefs ไม่มีobject_key/bucket/token/rawACL/recipientcontactsหรือsubjectของsourceที่ไม่มีสิทธิ์ ไม่มีpublicrecord endpointใน53

Queryวันอ้างอิงเลือกeffective_on<=asofกับrecorded_at<=known_at และsupersedes/eventversionที่สอดคล้อง ไม่ใช้notification/workerprocessed timeเป็นวันธุรกิจ สิทธิ์อ่านตรวจ **เวลาปัจจุบัน** ไม่ใช้known_atคืนgrantที่ถูกถอน คู่source/record/fileใช้currentACLและsecurityfloor ไม่เผยผ่านsearch snippets/totalcount/enumerror/filter/URLที่รู้เลข

Schema indexesเสนอเฉพาะnamespacecounter/context status/date/version FK/references ไม่indexเลขส่วนตัวหรือfulltextลับโดยไม่มีACL-aware design เอกสาร retention/legalholdยังTO VERIFY ใช้RESTRICT+เหตุการณ์ปิด/แก้ตามpolicy ไม่อ้างว่าต้องเก็บPIIตลอดไปหรือทำลายได้เมื่อVOID
