## 2 กรอกทีละขั้น

1. เปิดแบบเปล่าและอ่านชีตวิธีกรอกก่อน รักษาข้อความ “แบบทดลอง — ข้อมูลสมมติ ไม่ใช่แบบทางการ” และข้อมูลรุ่นไว้
2. ชีตผู้สมัครมีหัว machine field แถว 4 เริ่มกรอกแถว 5 หนึ่งแถวต่อหนึ่งคำขอทดลอง ห้ามเปลี่ยนชื่อหรือเพิ่มหัวคอลัมน์ ใช้ `row_id` ไม่ซ้ำภายในไฟล์ เช่น `000001` ชุดทดลองจองช่อง text ไว้ 20 แถว (5–24) ไม่กรอกเลยแถว 24; จำนวนนี้เป็นขนาดตัวอย่าง ไม่ใช่เพดานนำเข้าทางการหรือผล load test
3. กรอกรหัสหน่วยงาน สนาม ปีการศึกษา รอบ ประเภท ระดับ และช่วงชั้นจากทะเบียน/บริบทที่เลือกไว้ ไม่ค้นด้วยชื่อแล้วเดารหัส ชุดตัวอย่างใช้รหัสสมมติ `00101`, `00102`, `00001`, `00002`, `TEST_AY_2569` เท่านั้น รหัสเหล่านี้ไม่ได้ถูก seed เป็นทะเบียนจริง
4. ทุกเซลล์ข้อมูลตั้งเป็น **text** รวม ID เลขอ้างอิง รหัส ปี และวันที่ ชื่อไทยกรอกตามหลักฐาน ไม่แปลงเป็นอังกฤษหรือเดาตัวตนจากชื่อเหมือน ไม่บังคับทุกคนมีเลขบัตรไทย ชุดทดลองรองรับ `LOCAL_EVIDENCE` และ `PASSPORT`; ต้องมีนโยบายตัวตนที่รับรองก่อนเพิ่มประเภทสำหรับใช้จริง
5. วันที่ถ้าระบุเป็นข้อความ `YYYY-MM-DD` **ค.ศ.** เช่น `2000-01-02` ตาม protocol ของ schema ทดลองนี้ ไม่ใช้ `02/01/2569` หรือ Excel serial date แผ่นแสดงผลทางการภายหลังแปลงวันที่แสดง พ.ศ. แยกจากข้อมูลเครื่อง ไม่หัก 543 อัตโนมัติเมื่ออ่านข้อความกำกวม
6. กรอกชื่อเดิม นามสกุลเดิม ประโยคเดิมเมื่อมีข้อมูล ระบุปีพร้อมระบบปีที่ mapping รับรองก่อนใช้จริง `previous_qualification_year` ในตัวอย่างใช้ reference ปีการศึกษา `TEST_AY_2568` ไม่อนุมานสิทธิ์เลื่อนชั้นจากระดับที่เคยสอบ
7. ชีตหมายเหตุเริ่มแถว 5 หลายรายการใช้ `row_id` เดิม เช่น `000002` มีรายการชื่อเดิม นามสกุลเดิม และประโยคเดิมสามแถว เลือกรหัสหมายเหตุ/ชนิดหลักฐานจาก mapping รุ่น `DEMO_REMARKS_0.1.0` ซึ่งยัง TO VERIFY ไม่แตกข้อความคั่น comma แล้วอนุมัติเอง
8. `identity_evidence_ref` และ `evidence_ref` เป็น reference ของเอกสารกลาง ไม่ใช่ชื่อไฟล์ที่พิสูจน์หลักฐานได้หรือ URL/token ลับ ตัวอย่างขึ้นต้น `TEST_DOCUMENT_` ทั้งหมด **ยังไม่มีไฟล์หลักฐานจริง** ระบบจริงต้อง upload ผ่าน Document/FileVersion กลาง ตรวจชนิด quarantine scan และ ACL ก่อนอ้างใช้
9. บันทึกเป็น `.xlsx` ปิดและเปิดใหม่ ตรวจรหัส `000001` และชื่อ `ทดสอบก้อง000001` ไม่ใช้ CSV ที่สูญชนิด text ถ้าเลขถูก Excel แปลงจนศูนย์หาย ให้กลับไปข้อมูลต้นทาง ห้ามเติมศูนย์เดา
10. ในระบบจริงภายหลัง: เลือกบริบท → upload → ตรวจรายแถว/dry run → แก้ error → รับทราบ warning → ยืนยันผ่าน application service ระบบ 05 เดียวกัน **บทนี้ยังไม่มีขั้นตอนเว็บเหล่านี้** ไฟล์อ่านได้ไม่แปลว่าสมัครสำเร็จ ได้รับอนุมัติ ได้ที่นั่ง หรือมีผลสอบ

ช่องว่าง `""` และ `null` ที่อ่านจาก XLSX มีความหมายว่าไม่ระบุเหมือนกัน เฉพาะ field ที่อนุญาตว่าง ห้ามเปลี่ยนเป็น `0`, `"ไม่มี"` หรือค่าเดาเพื่อให้ผ่าน required field

## 5 สิทธิ์และความปลอดภัยก่อนใช้กับข้อมูลจริง

แอปต้อง resolve registry/policy/ปี/ประเภท/scope จาก server ไม่เชื่อข้อความรุ่นหรือค่า `official=true` ในไฟล์ ตรวจ account/action/หน่วยและสายสังกัด/วันมอบหมายทุก download upload preview export และ worker แบบ deny by default admin เทคนิคไม่รับสิทธิ์ธุรกิจอัตโนมัติ ผู้สร้าง template ไม่รับรองรุ่นของตนเอง รหัสอ้างเอกสารไม่ทำให้ข้าม file ACL ได้

อ่านแบบจำกัดขนาด ZIP expansion จำนวนแถว/เซลล์ เวลาและ memory; ปฏิเสธ macro encryption cell formulas และ external links ใช้เพดานทดลองจาก BLUEPRINT เป็น Proposal จนผ่าน load test ไม่ถือว่าการอ่านไฟล์ตัวอย่างเล็กผ่านเป็นหลักฐาน ZIP bomb protection

ไฟล์ข้อมูลจริงเป็น private ตามนโยบาย ไม่ commit ลง git หรือเผยผ่านหน้าดาวน์โหลดสาธารณะ ชุดที่ส่งมอบมีแต่ข้อมูลสมมติ การใช้ template ทางการต้องมีแหล่ง รุ่น layout/machine mapping ช่วงใช้และหลักฐานสิทธิ์ที่รับรองแล้ว ความหมาย ศ.3 ยังไม่ทราบ ห้ามเดาว่าเป็นใบสมัคร

## 6 ผลและสิ่งที่ยังไม่ได้รัน

ตรวจสร้าง เปิดอ่านกลับ typed text/ชื่อไทย/12 กลุ่ม/หมายเหตุ และตรวจ XML/ภาพของทุกชีตในสามไฟล์ตามหลักฐาน verification ใช้ Sarabun ปรับความกว้างให้เห็นข้อมูล ภาพ artifact renderer แสดง numeric-looking text ตัดศูนย์ จึงตรวจ XML/roundtrip และเปิดด้วย LibreOffice headless เพิ่มเพื่อยืนยันศูนย์นำหน้าในไฟล์จริง ไม่แก้ข้อมูลเพื่อให้ภาพดูถูก การทดสอบผ่านยืนยันเฉพาะไฟล์สมมติ ไม่รับรองกฎคุณสมบัติ แบบทางการ หรือข้อมูลบุคคลจริง ไม่ได้ทดสอบ Excel Desktop/LibreOffice ด้วยผู้ใช้งานจริง
